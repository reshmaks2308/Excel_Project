☕ Coffee Orders Dashboard in Excel 📊 Project Overview This project is an interactive Excel dashboard built to visualize and analyze coffee shop sales using sample data. It is designed to offer insights into customer behavior, product performance, and overall sales trends—perfect for showcasing skills in data analysis, dashboard design, and business intelligence.

🗃️ Dataset The project is based on three related tables:

Orders: Includes order ID, customer ID, product ID, order_date, quantity

Customers: Contains customer details like name, email, phone, location etc

Products: Contains product name, category, and price etc.

📈 Key Visualizations Total Revenue KPI: Displays overall earnings from coffee sales.

Revenue Over Time: A line chart showing trends in daily/weekly/monthly sales.

Top-Selling Products: A bar chart ranking drinks by revenue.

Donut Chart with Actual Revenue: Shows product-wise revenue breakdown (labels show currency, not percentages).

Orders by Month/Year: Highlights number of orders by month and year.

🛠 Tools & Techniques Excel Pivot Tables and Pivot Charts

Dynamic charts with Slicers and Timelines

Data formatting (currency, date/time grouping)

Custom labels in donut charts using value display instead of percentages

Clean dashboard layout with focus on usability and clarity

🎯 Skills Demonstrated Data cleaning and transformation

Data visualization and storytelling

Dashboard design best practices

Excel BI features (PivotTables, slicers, KPI formatting)
